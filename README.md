# TOLK — MVP Платформа для разговорной практики языков

Платформа для разговорной практики языков в микро-группах (строго до 5 человек) со студентами-тьюторами по методике **«Tengdosh tengdoshga»** (равный — равному).

MVP реализован как автономное веб-приложение / Telegram WebApp без внешних API-зависимостей (без Payme/Click API и без Google Meet API). Управление ссылками и сверка чеков осуществляются вручную через административную панель и личные кабинеты.

---

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
pip install fastapi uvicorn python-multipart httpx pillow
```

### 2. Запуск сервера
```bash
python run.py
```
После запуска откройте в браузере: **http://127.0.0.1:8000**

### 3. Сброс и повторный сид базы данных (при необходимости)
```bash
python seed_data.py
```

### 4. Запуск автоматических тестов
```bash
python test_platform.py
```

## 📱 Архитектура и Структура Экранов

### 💻 Экран 1: Главная страница (Лендинг)
- **Информационный блок**: Описание методики TOLK («Tengdosh tengdoshga», живая речь со студентами-тьюторами, группы строго до 5 человек).
- **Блок «Тарифы»**:
  - `Sinov davri`: 10,000 UZS / 1 занятие (пробный урок)
  - `Bez baryera (Русский)`: 200,000 UZS / месяц
  - `Speaking Club`: 300,000 UZS / месяц
  - `TOPIK I-II (Корейский)`: 400,000–500,000 UZS / месяц
- **Кнопка «Войти / Записаться»**: Вход по номеру телефона или выбор аккаунта в 1 клик.
- **Форма записи и оплаты**: При выборе любого тарифа открывается окно с реквизитами карты для перевода и загрузкой скриншота квитанции.

### 👤 Экран 2: Личный кабинет Ученика
*(Доступен только пользователю с ролью «Ученик»)*
- **Информация о курсе и группе**: Название группы, расписание, имя и контакт тьютора.
- **Кнопка перехода на урок**: Крупная кнопка `[ 🎥 Войти на урок в Google Meet ]` (открывает постоянную ссылку, настроенную тьютором).
- **Трекер дисциплины (Strict 3-Strike Rule)**:
  - Визуальный индикатор страйков: `[ 🟢 0 / 3 ]`, `⚠️ 1/3`, `🔴 2/3`, `⛔ 3/3`.
  - Текст: *«За 3 невыполненных ДЗ доступ к группе аннулируется»*.
  - При 3 страйках кнопка урока и форма сдачи блокируются, выводится баннер блокировки.
- **Форма сдачи Домашнего Задания**: Поле для ввода ссылки (Google Drive, видео, аудио) + кнопка `[ Отправить ДЗ ]` + история сданных заданий со статусами.

### 🎓 Экран 3: Личный кабинет Тьютора
*(Доступен только пользователю с ролью «Тьютор»)*
- **Мои группы**: Вкладки активных микро-групп (до 5 учеников).
- **Настройка урока**: Поле ввода и сохранения постоянной ссылки на Google Meet для каждой группы.
- **Электронный журнал (Журнал группы)**:
  - Список учеников группы с отображением текущих страйков и ссылок на сданные ими ДЗ.
  - Кнопки напротив каждого ученика:
    - `[ Check-in ✅ ]` / `[ Пропуск ❌ ]` (посещаемость)
    - `[ ДЗ сдано 👍 ]` / `[ ❌ Поставить Страйк ]` (начисление страйка за отсутствие ДЗ)
  - Кнопка `[ 💾 Сохранить результаты урока ]`.

### ⚙️ Экран 4: Панель Администратора (Админка)
*(Доступен только пользователю с ролью «Администратор»)*
- **Подтверждение Оплат (Manual Payments)**:
  - Список заявок с миниатюрой прикрепленного скрина чека/квитанции (клик открывает полный чек в модальном окне).
  - Кнопки `[ ✅ Подтвердить оплату ]` и `[ ❌ Отклонить ]`.
- **Управление микро-группами**:
  - Создание группы (язык, расписание, выбор тьютора, Google Meet ссылка).
  - Зачисление оплативших студентов в свободную группу (с жестким лимитом: **максимум 5 человек на группу**).
  - Исключение студента из группы при необходимости.
- **Лог нарушений (3-Strike Rule)**:
  - Автоматический список учеников с 3 страйками.
  - Кнопка `[ ⛔ Исключить из группы / Заблокировать доступ ]`.
  - Кнопка `[ Сбросить страйки ]`.

## 🛑 Выполнение жестких правил ТЗ

1. **Работа без сторонних API**: Никаких интеграций с Payme API, Click API, Google Calendar API или Google Meet API. Ссылки вводятся вручную текстом, оплаты проверяются администратором по скриншотам чеков вручную.
2. **База данных и жесткий RBAC**: Роли (`admin`, `tutor`, `student`) изолированы на уровне backend-зависимостей FastAPI. Ученик физически не имеет доступа к админке или чужим группам (возвращается HTTP 403).
3. **Mobile-First верстка**: Интерфейс оптимизирован под смартфоны и протестирован для запуска внутри Telegram WebApp (`telegram-web-app.js`).
4. **Автономность решения**: Чистый современный интерфейс (светлая тема, оранжевые акцентные кнопки `#FF6B00`, карточный дизайн, системные шрифты).
5. **Тестовые данные**: Проект сдан с полностью заложенными тестовыми аккаунтами (1 админ, 2 тьютора, 5 учеников в тестовой группе с 0, 1, 2 и 3 страйками + кандидаты с чеками).
